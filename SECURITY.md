# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in Kemal, please report it via
GitHub Private Vulnerability Reporting:
https://github.com/kemalcr/kemal/security/advisories/new

You can also email dogruyolserdar@gmail.com directly.

Please do not open a public GitHub issue for security vulnerabilities.

I'll try my best to respond within 72 hours and keep you updated on the fix timeline.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |
